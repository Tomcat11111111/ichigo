# Ichigo

現在只驗證核心手感。手感驗收通過之前，不開始第一關的 vertical slice。

## 現在：核心手感

用方塊與平台確認四件事是否成立：移動、跳躍、海浪傾斜、身體平衡。

這一階段的畫面只有幾何。男孩、殘骸、海浪的美術，以及生澀／熟練的動作回饋，留到下一階段。

手感原型用獨立的灰盒場景，不把機制寫進 `StormLevel`。`StormLevel` 維持空殼。

### 移動與跳躍

- A / 左方向鍵：向左
- D / 右方向鍵：向右
- Space：跳躍

角色能站上靜態平台。手感方向是反應直接、帶一點重量、容易控制。

初始參數，玩過之後才能改：

- 水平速度：180 px/s
- 跳躍初速：420 px/s
- 重力：1200 px/s²

### 海浪傾斜

傾斜的是角色腳下的甲板。這一階段不畫海面。

甲板以固定週期左右旋轉。會載人且會旋轉的甲板是移動平台，不是靜態障礙。

初始參數：

- 週期：4 秒
- 最大角度：±15°

### 身體平衡

角色站在甲板上時，身體上方對齊甲板法線。傾斜超過滑落角度後，角色沿甲板滑下。沒有平衡槽。

滑落角度低於甲板最大角度，所以每一週期都有一段可站立、一段會滑落。

初始參數：

- 滑落角度：12°

### 驗收

行為：

- 左右移動、跳躍，能站上靜態平台
- 甲板依週期旋轉
- 站在甲板上時，角色上方跟著甲板轉
- 超過滑落角度後，角色沿甲板滑落
- 畫面只有方塊與平台

手感要玩一次後再判斷：

- 滑落前能否預判
- 傾斜時跳躍是否仍可控
- 接受，或回到上面的初始參數再改

## 接著：第一關 Vertical Slice

手感驗收通過之後才規格化、才實作。

加入男孩、殘骸與海浪的美術，完成一段可以遊玩的短流程，包含生澀與熟練的動作回饋。
