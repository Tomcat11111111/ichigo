## 現在：核心手感

用方塊與平台確認移動、跳躍、海浪晃動、身體狀態是不是同一套系統。

這一階段的畫面只有幾何。男孩、殘骸、海浪的美術留到下一階段。身體狀態用方塊姿態表達。

手感原型用獨立的灰盒場景，不把機制寫進 `StormLevel`。`StormLevel` 維持空殼。

玩家輸入的是意圖。角色只有一條速度。加速度來自輸入，也來自坡度、甲板晃動，以及腳下還有沒有支撐。沒有平衡槽。姿態只反映這條速度，不改寫它。

要回答的是：單靠移動、慣性與環境互動，能不能產生身體掙扎感。

### 移動與跳躍

- A / 左方向鍵：向左加速
- D / 右方向鍵：向右加速
- 放開方向鍵：停止的意圖。平地很快停下；斜坡或甲板正在晃時，剩餘速度留著
- 反方向：先把現有速度減到零，再往反方向加速
- Space：跳躍。水平速度沿用起跳當下的速度
- Shift : 衝刺

步伐隨速度改變。
角色能站上靜態平台。平地要反應直接、帶一點重量。明顯的滑動只出現在斜坡與甲板晃動時。

初始參數，玩過之後才能改：

- 最高水平速度：180 px/s
- 加速度：900 px/s²
- 平地鬆鍵摩擦：1200 px/s²
- 反向煞車：1600 px/s²
- 跳躍垂直初速：420 px/s
- 重力：1200 px/s²

### 海浪晃動

晃動的是現在這塊甲板。補上海面。

甲板以固定週期升降並左右傾斜，像浮在海浪上。升降與傾斜同一週期、同一相位：升到最高時，傾斜也到最大。會載人且會動的甲板是移動平台，不是靜態障礙。

可用摩擦隨坡度與甲板角速度下降。接近最大傾角，或正轉得最快時，摩擦變低，鬆鍵會繼續滑。

初始參數：

- 週期：4 秒
- 最大角度：±15°
- 中心升降：±32 px

### 身體狀態

- 穩定：坡度小、甲板角速度低、速度變化小，且腳下有支撐。軀幹直立，步伐均勻。
- 失衡：坡度、甲板角速度或橫向加減速變大，腳下仍有支撐。軀幹傾斜，手臂張開，步伐變亂。
- 補救：已經失衡，且玩家正在減速或反向。跨步變大，身體更傾。伸手只是姿態。
- 跌倒：腳下失去支撐並落下。落下後可以落在地面或靜態平台。

### 驗收

行為：

- 平地左右加速，鬆鍵很快停下，反向會先減速再轉向前進
- 起跳的水平速度沿用起跳當下的速度
- 能站上靜態平台
- 甲板依週期升降並傾斜
- 坡度變大或甲板轉快時，鬆鍵會繼續滑
- 穩定、失衡、補救、跌倒能從方塊姿態分辨
- 畫面只有方塊與平台

手感要玩一次後再判斷：

- 在晃動的甲板上，移動是否仍自然可控
- 失衡與補救的姿態，能否讓人察覺自己即將失控
- 能否靠預判、減速、反向或跳躍回到可控
- 接受，或回到上面的初始參數再改

## 接著：第一關 Vertical Slice

手感驗收通過之後才規格化、才實作。

加入男孩、殘骸與海浪的美術，完成一段可以遊玩的短流程，包含生澀與熟練的動作回饋。

如果移動、慣性與環境互動已經夠，就把這套移動延伸到完整關卡。如果不夠，再考慮抓握、蹲伏或主動保持平衡。
